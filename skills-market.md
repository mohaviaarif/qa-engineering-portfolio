# skills-market.md
Source: P@SHA Skills Survey 2025 (pages 18, 21, 22) + 10 live Pakistan QA job postings

## Testing Tools & Frameworks
| Tool | Report (industry-wide) | Job posts (10 scanned) |
|---|---|---|
| Playwright | Rising, code-driven shift | 40% (top tool) |
| Selenium | Foundational | 30% |
| Appium | Steady/niche | 30% |
| Cypress | Valued for senior roles | 20% |
| TestComplete | Modest, maintenance projects | 10% |
| Postman / API Testing | — | 40% |
| ISTQB (cert) | High entry-level relevance | Implied via "QA Training + Cert" (3,690 demand) |

## Programming Languages (in QA context)
| Language | Job posts |
|---|---|
| JavaScript | 30% |
| SQL | 30% |
| TypeScript | 20% |
| Java | 20% |
| Python | 10% |

**Key finding:** Playwright (40%) beats Python (10%) 4-to-1 in real QA postings — confirms TypeScript/Playwright over a Python-based stack.

## Database
- Relational (PostgreSQL, MySQL, MS SQL) — dominant, highest demand across all experience levels
- Non-relational (MongoDB) — growing, but secondary for QA entry roles

## Testing Methodologies (job posts)
Regression (70%), Manual/Verification (60%), Functional (40%), Integration (40%), API (40%), Exploratory (30%), End-to-End (30%)

## Version Control / CI
- Git — #2 in industry-wide upskilling demand (7,560)
- CI/CD — 40% of job posts

## Top Soft Skills Requested
Communication (80%), Attention to Detail (60%), Analytical Skills (60%), Cross-functional Collaboration (70%)
