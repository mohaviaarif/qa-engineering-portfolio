# QA Engineering Portfolio

A daily, hands-on QA practice log — built as part of a 90-day sprint to break into
Quality Assurance / Software Testing roles. Every day includes real, dated proof
of work: test cases, bug reports, and testing notes — not just tutorials followed.

## What this repo contains
- **Test cases** — written from scratch for real features, following a consistent
  format (steps, test data, expected vs. actual result, pass/fail status)
- **Bug reports** — genuine defects found while testing, logged through a full
  find → report → retest lifecycle
- **Testing notes** — fundamentals, applied and explained in my own words, not copied
- **A live test subject** — most testing here is done against CyberSentinel AI, a
  working ML-based phishing/malware detection app I built, rather than a toy demo app

## Stack this month
Testing fundamentals (ISTQB) · API testing (Postman) · SQL · Playwright/TypeScript ·
Git/GitHub Actions

This stack was chosen based on real market data — a review of the P@SHA Skills
Survey 2025 plus 10 live Pakistan QA job postings — not guesswork.
