# QA Engineering Portfolio

A hands-on manual testing portfolio, built through a structured 90-day practice program toward a Junior QA/SQA Engineer role. It contains original test cases, bug reports, and exploratory testing notes.

**System under test:** CyberSentinel AI, a live, self-built ML-based phishing, malicious URL, and malware detection platform (https://cybersentinell-frontend.vercel.app).

## Start here
- [manual-testing/](manual-testing/): test cases, exploratory testing charters, and bug reports
- [threat-model.md](threat-model.md): modules, trust boundaries, and risks
- [notes.md](notes.md): ISTQB CTFL v4.0 notes and test design techniques
- [skills-market.md](skills-market.md): market research behind the skill stack
- [cv/](cv/): current CV versions

## Skills
- **Practiced so far:** manual and functional testing, exploratory testing, test case design (equivalence partitioning, boundary value analysis), bug reporting, security-focused testing
- **In progress:** API testing (Postman), SQL, Playwright/TypeScript automation
- **In use:** Git/GitHub

## Research basis
The skill stack was chosen from real market data: the P@SHA Skills Survey 2025 plus 25 live Pakistan QA job postings. Details are in skills-market.md.
