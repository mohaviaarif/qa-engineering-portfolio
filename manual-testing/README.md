# Manual Testing

Manual and exploratory testing of **CyberSentinel AI**, a live, self-built ML cybersecurity platform that detects phishing emails, malicious URLs, and malware.

**System under test:** https://cybersentinell-frontend.vercel.app

## What's in this folder
- [test-cases.md](test-cases.md): written test cases with priority, type, and status, using equivalence partitioning and boundary value analysis
- [exploratory-testing.md](exploratory-testing.md): exploratory testing charters and triage of findings
- [bugs.md](bugs.md): formal bug reports with severity

## Where to start
Read exploratory-testing.md first for the overview, then bugs.md for the findings.

## Status
Work in progress. This portfolio is updated as part of a structured 90-day practice program.
